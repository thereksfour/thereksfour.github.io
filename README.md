# cccz security profile

Static GitHub Pages site for `thereksfour.github.io`.

## Local preview

Open `index.html` directly in a browser, or run:

```sh
python3 -m http.server 8080
```

Then visit:

```text
http://localhost:8080
```

## Deploy

Create a GitHub repository named:

```text
thereksfour.github.io
```

Then push this directory to the repository's `main` branch. GitHub Pages will publish it at:

```text
https://thereksfour.github.io
```
